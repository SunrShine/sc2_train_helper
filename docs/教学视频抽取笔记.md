# 教学视频 → BO 步骤 抽取笔记

目标：把 B 站合集【星际一招鲜】的 100 条招式视频，转成结构化 BO 步骤。

## 已经验证可行的链路

1. `yt-dlp`（纯 Python 版，装在 `.tmp/tools/pkg`，用 `PYTHONPATH` 调）下 720p：
   `-f "30064+30280"`，360p 是 `30016+30232`。
2. 抽帧：`tools/video_frames.py`
   - 宫格：`--step 8 --cols 3 --rows 3 --width 640`，一张图 9 帧，帧内容 640 宽可读
   - 时钟：`--clock-box x,y,w,h` 把指定区域放大后贴到每帧左上角（版式随视频变，需逐条校准）
3. 画面标注是作者手打的大字，**整帧看能读**；ASR 转写质量差，只能交叉核对。

## 踩过的坑

- **时钟位置各不相同**：#28 在左下角（0,480,80,44），#36 在画面左上（随 SC2 UI），
  用固定裁剪会裁到地形。最稳的是直接看宫格里每帧的计时器（640 宽可读）。
- **ASR 不可用**：背景音乐大、语速快，实测「第N步」大量丢失，转写出现
  「何必E」「普子战」这类无意义串；加热词也没明显改善。
- **不是每条都有编号**：#28 是 Maru vs INnoVation 的对局复盘，只有解说标注，没有步骤号。
- **自动挑标注失败**：用「亮像素成片」检测会把爆炸、雪地、矿脉当成字幕，
  裁出来的块没有字（试过按 bbox 裁、按固定带裁，都不稳）。所以还是逐帧读宫格最可靠。

## 成本

一条 6 分钟视频：8 秒采样 = 约 45 帧 = 5 张 3x3 宫格图（每张约 1~2k vision token）。
读+转写约 3 分钟/条。TvT 33 条 ≈ 165 张图。
