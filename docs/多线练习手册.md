# 多线练习手册（本地录像驱动）

这份手册配合 `python -m replay_analyzer micro` 用：**先用工具量出你的操作习惯，再照着 drill 练，一周后再量一次。**

---

## 0. 先把"多线"定义清楚

多线不是"同时操作两个地方"——人只有一双手，真正发生的是**注意力分时复用**：

```
0.0s  看主部队 → 下令（A 到前线）
2.5s  切到空投船 → 下令（投下去）
4.0s  切回主部队 → 补一队兵
6.0s  切到二矿 → 拉农民
```

所以能测量的是三件事，工具对应三个指标：

| 指标 | 含义 | 说明 |
|---|---|---|
| **视角切换 / 分** | 你的注意力切得多快 | 太低=盯一个屏幕看到死；太高=每条线都只瞄一眼 |
| **多线窗口 / 分** | 同一段时间里真的在两条线上都下了指令的次数 | 6 秒内、两个相距 ≥25 格的位置各 ≥2 条指令 |
| **多线覆盖 %** | 这些窗口占整局时间的比例 | 越高说明你的"多线时间"越多 |
| **不下指令空档** | 视角在动、单位在选，但 8 秒以上没发出任何命令 | 这是最常见的"假忙碌" |

> 下面的区间是**经验值**，不是官方或职业数据。它的用途是让你有个可以打勾的靶子，练到超出就往上调。

---

## 1. 三个 drill

### Drill A · 视角节奏（每天 5 分钟，进天梯前做）

**目标**：把"切视角"变成有节奏的动作，而不是被打才切。

1. 开一张自定义图（或人机），只造 3 个兵营 + 1 个基地，不打架。
2. 用手机计时器或节拍器，**每 4 秒切一次视角**：主基地 → 集结点前方 → 生产建筑 → 回主基地。
3. 硬性规则：**每次落地 2 秒内必须下 1 条指令**（哪怕是让农民走一步）。做不到就当场重来。

**判据**：`micro` 报告里 `视角切换 12–20 次/分`、`单次停留中位 1.5–2.5s`。
**典型错误**：切了但不下令 → `不下指令空档` 飙升，这是"假 APM"。

### Drill B · 双线例行（对局中执行，20 秒循环）

**目标**：让"两条线同时有动作"成为肌肉记忆。

1. 编队固定：`1` 主部队、`2` 二线（空投/侧翼/埋地）、`3` 生产、`4` 偷家小队。
2. 每 20 秒做一次循环：`1` → 下令（A 到位置）→ 空格/编队 `2` → 下令 → `3` → 补生产 → 回 `1`。
3. 关键不是快，是**两条线的指令都要有目的**：一条压位置，一条换资源/牵制。

**判据**：`多线窗口 ≥0.8 个/分`、`覆盖 ≥10%`。
**进阶**：同样两线，把窗口内的视角切换次数压下来（报告里"含金量最高"的窗口就是你的上限参考）。

### Drill C · 窗口复盘（每局后 5 分钟，只看 3 个窗口）

1. 打开 `xxx-micro.html`，看第五节的窗口表，挑 **含金量最高的 3 个**（工具已经标出来）。
2. 每个窗口展开"操作序列"，按顺序抄下来，然后回答三行：
   - ① 我先做的是哪条线？这条线当时是"必须做"还是"顺手做"？
   - ② 序列里有没有多余动作（重复的视角、重复的编队、点了又取消的指令）？
   - ③ 如果换顺序（先做另一条线），会多赢/少亏什么？
3. 只写**一条**下次可执行的规则，例如："投放前先把主部队 A 出去，投完再回来看主部队。"

**判据**：每周能写出 ≥3 条可执行规则，并且下一周的报告里能看到对应指标变化。

## 2. 一周怎么排

| 时间 | 内容 | 用时 |
|---|---|---|
| 周一 | Drill A（视角节奏）+ 2 局天梯 | 40 分钟 |
| 周三 | Drill B（对局里刻意做双线）+ 2 局 | 60 分钟 |
| 周五 | Drill C（复盘本周 5 局，只挑窗口） | 40 分钟 |
| 周日 | 跑一次批量趋势，对比上周均值 | 10 分钟 |

批量趋势命令（拿你最近的录像算一遍，看自己位置）：

```powershell
python -m replay_analyzer micro "C:\Users\sun\Documents\StarCraft II\Accounts\556922532\5-S2-1-8354391\Replays\Multiplayer" --limit 40 -o reports\micro-trend.html
```

## 3. 打分卡

| 指标 | 起步 | 熟练 | 目标 |
|---|---|---|---|
| 视角切换 / 分 | <8 | 8–12 | 12–20 |
| 单次停留中位 | >3s | 2–3s | 1.5–2.5s |
| 多线窗口 / 分 | <0.3 | 0.3–0.8 | ≥0.8 |
| 多线覆盖 | <5% | 5–10% | ≥10% |
| 不下指令空档 / 局 | >150s | 60–150s | <60s |
| 交火后首次指令延迟 | >2s | 1–2s | <1s |
| 用到的编队槽 | <3 | 3–4 | ≥5（主/二线/生产/偷家/骚扰） |

每项在报告里都有对应数字，一周只看一次，不要每天盯。

**职业/高手的录像**（用来看"窗口"能密到什么程度）：

## 5. 用对照组定靶子（职业选手当目标线）

自己跟自己比只能知道"有没有进步"，跟职业选手比才知道"离目标多远"。

```powershell
# 建库（只读，不改你的文件夹）
python -m replay_analyzer library --me "…\Replays\Multiplayer" --pro replays\pro -o reports\library.html

# 同对位对照组
python -m replay_analyzer compare --me "…\Replays\Multiplayer" --pro replays\pro\maru `
    --matchup TvZ --limit 30 -o reports\compare-tvz.html --open
```

报告里有两块东西：

1. **中位数对比表**：视角切换、停留、多线密度、覆盖、指令、空档，六项一次看完；
2. **窗口配对**：工具把你的多线窗口和职业选手里"形状最像"的窗口并排，两边都展开完整操作序列。
   看的时候只问一句：**同样的两条线，他的第一条指令给了哪一边。**

参考数据（自己 30 局 TvZ vs Maru 12 局 TvZ，2026-10 抓的）：

| 指标 | 我 | Maru | 倍数 |
|---|---|---|---|
| 视角切换 / 分 | 11.1 | 8.2 | 1.3× |
| 单次停留 | 1.8s | 1.3s | 1.4× |
| 多线窗口 / 分 | 1.09 | 3.12 | **0.35×** |
| 多线覆盖 | 11.2% | 38.9% | **0.29×** |
| 指令 / 分 | 43 | 74 | 0.58× |
| 不下指令空档 | 107s | 10s | 10× |

两个反直觉的点，值得记住：

- **他的视角切换其实比你少**（8.4 vs 11 次/分），停留更短但更"值钱"——他每次都带着指令去，不像我们频繁切过去只瞄一眼。
- 差距不在"有没有开两条线"，而在**每个窗口里做了几件事**：他一个窗口 11 条指令，你 7 条。

注意：职业比赛节奏比天梯紧，绝对值会偏高，**看倍数、看趋势，别把 2.26 当成硬指标**。
每周跑一次，只盯两个数：多线窗口/分、不下指令空档。

## 6. 把一段操作做成 GIF 卡片

报告里的"操作序列"是文字，很难一眼看出**两条线在地图上的位置关系**。卡片把同一段操作渲染成小地图动画：

`powershell
# 单张：自动挑这局"最满"的多线窗口；也可以指定时间
python -m replay_analyzer card "…\maru_vs_xxx.SC2Replay" --player Maru --at 7:09 --duration 8 -o reports\cards\maru.gif

# 批量：对照组里每个配对，各生成"我的一张 + 他的一张"
python -m replay_analyzer compare --me "…\Multiplayer" --pro replays\pro\maru --matchup TvZ --cards reports\cards
`

怎么读这张卡片：

| 画面元素 | 含义 |
|---|---|
| 白色方框 | 当时屏幕上看见的区域（视角在哪） |
| 金/白十字 | 刚下的指令落点；越亮越新（3 秒内会停留） |
| 红色虚线圈 A / B | 这一波的两条线（相距 ≥25 格的两处操作） |
| 红点 / 蓝点 | 你方 / 对方单位；方块是建筑，小点是农民 |

看的时候只注意两件事：**① 视角在 A、B 之间切了几次、每次停留多久；② 每条线的第一条指令是什么时候、给了谁。**

没装 ffmpeg 也能量：会自动退化成 PNG 序列 + 一个可逐帧浏览的 play.html。

## 7. 这套指标的边界

- replay 只记录**指令、视角、选中、编队**，没有鼠标轨迹，也没有点击精度 → 无法评价"点得准不准"。
- 多线窗口是启发式：同一场团战里点两下不同位置也会被算进去，所以要结合"含金量"（指令数 × 跨度）看。
- 合作模式、自定义图、AI 对战里"运营节奏"含义不同，指标只做参考。
- 录像里不含"你当时在想什么"，所以复盘的重点永远是**顺序和取舍**，不是数字本身。
